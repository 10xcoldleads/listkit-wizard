# ListKit hot-lead forward

When a prospect reply is a NOW deal or a trust/sending-domain question, ping the client's real operator with a short note plus a full contact block — after (or alongside) the ListKit reply, never instead of it.

## HOT
Live surplus/bid/auction/named inventory, or trust/domain legitimacy questions (operator should reach them from the real company inbox NOW).

## NOT HOT
Later/not-now, keep-in-mind, OOO, unsub, wrong person with no inventory (trust/domain still forwards).

## Contact block
Every real field you have; omit blanks; never invent. Include name, title, org, city/state, email, phone, LinkedIn, website, CCs.

## Dedupe
Log keyed by lead email + inbound id/hash. New inbound = new key.

## Delivery
Use whatever notify path the operator configured (chat ping, email, etc.). Core setup does not require a Gmail plugin — if no path is set, surface the contact block to the operator in chat.
