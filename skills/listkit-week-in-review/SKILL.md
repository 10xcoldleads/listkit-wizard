# ListKit week-in-review

Send the client a weekly progress report covering the previous calendar week in their timezone. Always produce it. Never skip because results felt thin.

## Goal
The client must feel progress. Lead with momentum and concrete wins. Quiet weeks still show proof of work. Never invent numbers.

## Data sources (live only)
1. ListKit Master Inbox + campaign counts
2. Your logs of replies, retags, follow-ups
3. Proof-of-work activity (sends, imports, hygiene)
4. Hot-lead forward log (summarize, do not re-forward)

## Sections (in order)
1. Last week overall
2. Proof of work
3. Reply sentiments
4. Opportunities
5. Yeses / concrete inventory
6. 2–4 next-week actions

## Delivery
Deliver via whatever channel the operator configured for client reports (email, chat, paste-back). If no send path is set up yet, give them the finished draft in chat. No Gmail marketplace plugin is required for core setup.
